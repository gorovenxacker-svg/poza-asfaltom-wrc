# Поза асфальтом

Навчальний персональний сайт про WRC та ралі. Мова — українська. Тема, тексти й згенеровані ілюстрації створені як демонстраційний фан-блог; це не біографічні дані замовника.

## Запуск

Розпакуйте архів повністю та відкрийте `index.html` у браузері. Інтернет, Node.js, встановлення залежностей і збірка не потрібні. Не відкривайте HTML безпосередньо всередині ZIP.

## Три сторінки різного наповнення

| Файл | Зміст |
| --- | --- |
| `index.html` | Вступ до WRC, головна ілюстрація, покриття, короткий опис ралі |
| `gallery.html` | Три покриття: гравій, асфальт і сніг; фільтри та збільшений перегляд |
| `about.html` | Ролі пілота й штурмана, ралійний день, стенограма та словник |

`styles.css` — спільне оформлення; `script.js` — лише фільтрація та діалог галереї; `assets/` — локальні WebP-зображення та SVG-значок. `LECTURE-NOTES.md` — конспект наданих лекцій. `EXPLANATION.md` — пояснення реалізації для захисту.

## Відповідність завданню

- Три окремі HTML-документи зі спільною навігацією.
- Семантичні `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Grid для головної композиції, галереї, етапів і сторінки про захоплення.
- Flexbox для меню, панелі фільтрів, підписів і футера.
- Mobile-first і точки зламу 36rem, 56rem, 72rem (576, 896, 1152 CSS px за базового шрифту 16px).
- `meta viewport`, `clamp()`, відносні одиниці, `minmax(0, 1fr)`.
- Адаптивні WebP 640/1280px, `srcset`, `sizes`, `picture`, `alt`, `width`/`height`, відкладене завантаження другорядних зображень.
- Видимий фокус, посилання переходу до вмісту, `aria-current`, кнопки від 44px, підтримка reduced motion.
- Галерея доступна і без JavaScript: усі роботи показані, зображення відкриваються звичайними посиланнями.

## Перед здачею

За бажанням додайте власне ім’я та групу у футер, замініть демонстраційні тексти власними спостереженнями. Прочитайте `EXPLANATION.md`, щоб пояснити використані прийоми.

### Перевірка в браузері

Відкрийте всі три сторінки. Через інструменти розробника перевірте ширини 320, 375, 768, 1280 і 1920px, а також проміжні значення біля точок зламу. Горизонтальної прокрутки бути не повинно. Перевірте збільшення тексту до 200%, клавішу Tab, видимість фокусу й відкриття посилань клавішею Enter.

У галереї перевірте кількість робіт: усі — 3, гравій — 1, асфальт — 1, сніг — 1. Відкрийте ілюстрацію, закрийте кнопкою або Escape; фокус має повернутися на початкове посилання. На третій сторінці відкрийте та закрийте відповіді.

Статична перевірка локальних ресурсів, фрагментів посилань і структури HTML виконана. Автоматичний запуск браузера в середовищі підготовки не вдався; візуальна перевірка адаптивності та інтерактивності потребує виконання у звичайному браузері. 

## Публічний репозиторій

Код сайту: https://github.com/gorovenxacker-svg/poza-asfaltom-wrc . Для здачі можна прикріпити це посилання. `index.html` розміщено в корені, зображення — у `assets/`.

Вихідні лекції й архіви практик не включено до публікаційного пакета. Конспект містить стислий переказ матеріалу, а не копію презентацій.
